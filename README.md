# jyluo research source snapshot

Source, configuration and experiment documentation from `/home/zhsu/jyluo`, saved on 2026-10-26.
The original directory structure is preserved for local experiment code and the Fetch project.
Downloaded upstream projects are represented by pinned revisions, local patches and exact
source overrides under `upstream_changes/` and `upstream_overrides/`.
The upstream licenses continue to apply; this snapshot does not claim authorship of upstream code.

This repository excludes datasets, model weights, training checkpoints, virtual environments,
compiled caches and private credentials. Those required for preservation belong in the separate
download backup. Trained checkpoints and historical evaluation records must not be discarded
merely because an experiment could be run again.

`upstream_changes/*/normalized.patch` ignores line-ending-only differences. Exact original
unstaged/staged patches and original Git metadata are preserved in the separate backup.
Source overrides preserve the selected working-file bytes. The source directory itself was
not committed, reset or cleaned during this export.

Snapshot prepared with an AI coding assistant. No experiments were rerun for this export.
