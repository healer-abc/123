# 同一冻结 π0 检查点在 Farama MetaWorld v2 与 3.1.1 v3 的结果

| 任务语义 | 旧 v2 曾成功 | 新 v3 曾成功 | 新 v3 最后一步成功 |
|---|---:|---:|---:|
| assembly | 10/20 | 8/20 | 7/20 |
| shelf-place | 8/20 | 8/20 | 5/20 |
| disassemble | 6/20 | 5/20 | 4/20 |
| peg-unplug-side | 13/20 | 14/20 | 1/20 |
| stick-pull | 0/20 | 3/20 | 2/20 |
| 总计 | 37/100 | 38/100 | 19/100 |

两轮均冻结同一权重，使用相同的 42–61 种子序列、步数上限和 success_once 口径。
Farama v3 环境与旧 v2 的任务实例、物理版本不同，不能将每行差值解释为严格配对的模型性能提升。
MTBench 2026 年 4 月的约 90% 是另一套 Isaac Gym/Franka 环境训练约 200M 帧后的强化学习成绩，不是本 π0 的对照目标。
